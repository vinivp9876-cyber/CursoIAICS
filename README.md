# Gestos Inteligentes

Aplicação web que reconhece gestos da mão em tempo real usando a webcam e MediaPipe, registrando os eventos no Supabase.

## Objetivo
Reconhecer três gestos da mão (palma aberta, punho fechado e polegar para cima), mostrar uma resposta na interface e persistir cada evento em um banco de dados PostgreSQL via Supabase.

## Requisitos
- Node.js LTS
- Navegador moderno com webcam (localhost ou HTTPS)
- Conta e projeto no Supabase

## Estrutura
```
index.html      # Interface (HTML)
style.css       # Layout e estados visuais
script.js       # Webcam, MediaPipe, gestos e chamadas à API
server.js       # Servidor Node.js/Express que acessa o Supabase
package.json    # Dependências e scripts
.env            # Chaves privadas (não commite)
.gitignore      # Ignora .env e node_modules
```

## Instalação
```bash
npm install
```

## Configuração
Crie um arquivo `.env` na raiz com valores do seu projeto Supabase:

```
SUPABASE_URL=https://SEU_PROJETO.supabase.co
SUPABASE_SECRET_KEY=sb_secret_SUA_CHAVE
PORT=3000
```

A chave secreta fica apenas no servidor. Nunca inclua `.env` no Git (já está no `.gitignore`).

## Banco de dados
No painel do Supabase, SQL Editor, execute:

```sql
create table if not exists public.gestos_registrados (
    id bigint generated by default as identity primary key,
    gesto text not null,
    confianca numeric(5,4),
    data_hora timestamptz not null default now()
);
create index if not exists idx_gestos_registrados_data_hora
on public.gestos_registrados (data_hora desc);
```

## Execução
```bash
npm start
```
Abra `http://localhost:3000`, permita a câmera e faça os gestos.

## Gestos
- Palma aberta: mensagem de boas-vindas.
- Punho fechado: mensagem de conclusão.
- Polegar para cima: aprovação e incrementa contador.

## Evitar duplicados
O mesmo gesto não é registrado a cada frame. Um novo registro ocorre apenas quando o gesto muda ou após um intervalo mínimo de 1,5 segundos.

## Segurança
A chave secreta do Supabase nunca é enviada ao navegador. O front-end chama apenas a API local (`/api/gestos`), e só o servidor acessa o Supabase.

## Limitações
A classificação usa regras geométricas simples sobre os landmarks e pode variar com iluminação, ângulo e distância da mão.
